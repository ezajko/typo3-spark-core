Configuration & Options
=======================

Spark Core extends standard TYPO3 fields to provide design system controls directly in the Backend.

General Settings
----------------

Container Layouts
~~~~~~~~~~~~~~~~~
Available in the **Appearance** tab for most elements.
* **Layout (Container)**: Controls the width of the outer container (``container``, ``container-fluid``, ``container-xl``, etc.).
* **Inner Layout**: Controls the behavior of the inner wrapper (e.g., ``Row``, ``Flex Center``).

Visual Classes
~~~~~~~~~~~~~~
* **Header Class**: Visual override for header tags (e.g., display an H2 looking like an H1).
* **Variant**: Color themes (Light, Dark, Primary) available for specific elements like Cards and CTAs.

Grid Settings
-------------

When using Grid Containers or specific elements, a **Grid Settings** palette is often available:

* **Horizontal Gutter (gx)**: Controls horizontal gap between columns (0-5).
* **Vertical Gutter (gy)**: Controls vertical gap between rows (0-5).
* **Vertical Alignment**: Align items to Top, Center, or Bottom.
* **Padding (Vertical/Horizontal)**: Add inner padding (``py-*``, ``px-*``) to the element.
